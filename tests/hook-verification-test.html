Hook 功能验证测试

验证 Hook 是否真的拦截了请求、是否添加了请求头、是否检查了请求体。

验证目标：
1. Hook 是否真的拦截了 XMLHttpRequest 的 send 方法
2. Hook 是否添加了请求头（tx_webkit_body_uuid）
3. Hook 是否检查了请求体（shouldNativeHandleHTTPBody）
4. Hook 是否保存了数据到原生（saveParamsToNative）

验证 1：Hook 是否拦截了 XMLHttpRequest 的 send 方法

方法：Hook XMLHttpRequest 的 send 方法，然后发起请求，检查是否被拦截。

验证 2：Hook 是否添加了请求头（tx_webkit_body_uuid）

方法：发起一个 XMLHttpRequest 请求，检查服务器收到的请求头中是否有 tx_webkit_body_uuid。

验证 3：Hook 是否检查了请求体（shouldNativeHandleHTTPBody）

方法：测试 shouldNativeHandleHTTPBody 方法，看它如何判断是否处理请求体。

验证 4：Hook 是否保存了数据到原生（saveParamsToNative）

方法：调用 saveParamsToNative 方法，观察返回值。

验证 5：实际测试 Hook 代码是否被执行

方法：创建一个 XMLHttpRequest，检查它的 send 方法是否被 Hook 修改。

验证 6：测试 Hook 的完整流程

方法：调用 hookXMLHttpRequest，然后发起一个 POST 请求，检查完整的流程。
