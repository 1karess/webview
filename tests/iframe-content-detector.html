🔍 iframe 内容检测工具

利用 iframe 内的用户内容检测登录状态（不依赖 Bridge）

步骤 1: 在 iframe 中加载 Reddit

步骤 2: 检测方法选择

方法1: iframe 内执行 fetch（推荐）

在 iframe 内注入脚本，让 iframe 内的代码执行 fetch 请求。因为 iframe 和新窗口共享 Cookie，iframe 内的 fetch 应该能携带 Cookie。

方法2: 检测 iframe 内的 UI 元素

尝试访问 iframe 的 DOM，检测是否有登录相关的 UI 元素（通知图标、用户头像等）。受同源策略限制，可能无法访问。

方法3: postMessage 通信

通过 postMessage 与 iframe 通信，让 iframe 内的代码执行检测并返回结果。需要 iframe 内配合。

方法4: 检测 iframe 内的 Cookie（如果同源）

如果 iframe 和父页面同源，可以直接访问 iframe 内的 Cookie。
