🔍 iframe 内部检测工具

💡 为什么新窗口登录可以同步到 iframe，但检测方法不行？

关键区别：

  • Cookie 共享：发生在 WebView 层面，是自动的，不需要 JavaScript 访问
    → 新窗口登录 → Cookie 存储在 WebView → iframe 加载时自动携带 Cookie → UI 显示已登录 ✅
  • JavaScript 访问：受 同源策略限制，父页面无法访问 iframe 的内容
    → 父页面尝试访问 iframe → 同源策略阻止 → 无法执行 iframe 内的代码 ❌

解决方案：创建一个可以在 iframe 内直接运行的测试页面，或者使用 URL 参数传递检测脚本。

方法1: 在 iframe 中加载测试页面（推荐）

将测试代码嵌入到 Reddit URL 中，让 iframe 加载时自动执行检测。

方法2: 使用 Bookmarklet（手动方式）

在 Reddit 页面中手动执行检测代码。

步骤：

  1. 在 iframe 中打开 Reddit 并登录
  2. 在 Reddit 页面的地址栏输入以下代码（或创建书签）：
javascript:(function(){fetch('https://oauth.reddit.com/api/v1/me',{credentials:'include'}).then(r=>r.json()).then(d=>{const h=!!(d.name||d.id||d.username);alert('登录状态: '+(h?'已登录 - '+d.name:'未登录')+'\n\n完整数据:\n'+JSON.stringify(d,null,2))})})();

或者点击下方按钮复制代码

方法3: 创建同源测试页面

创建一个可以在 Reddit 域名下运行的测试页面（需要部署到 Reddit 或使用代理）。

方法4: 通过 URL 参数传递检测脚本

尝试通过 URL 参数将检测代码传递给 iframe（可能被 CSP 阻止）。
