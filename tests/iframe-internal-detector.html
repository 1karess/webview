🔍 iframe 内部检测工具

💡 为什么新窗口登录可以同步到 iframe，但检测方法不行？

关键区别：

  • Cookie 共享：发生在 WebView 层面，是自动的，不需要 JavaScript 访问
    → 新窗口登录 → Cookie 存储在 WebView → iframe 加载时自动携带 Cookie → UI 显示已登录 ✅
  • JavaScript 访问：受 同源策略限制，父页面无法访问 iframe 的内容
    → 父页面尝试访问 iframe → 同源策略阻止 → 无法执行 iframe 内的代码 ❌

解决方案：创建一个可以在 iframe 内直接运行的测试页面，或者使用 URL 参数传递检测脚本。

方法1: 在 Reddit iframe 中执行检测（推荐）⭐

工作原理：先加载 Reddit 到 iframe，然后在 Reddit 页面中注入检测脚本。因为脚本在 Reddit 页面内执行，可以访问 Reddit 的 Cookie。

步骤：

  1. 点击下方按钮，在 iframe 中加载 Reddit
  2. 等待 Reddit 加载完成（如果已登录，会显示登录状态）
  3. 点击"在 Reddit 页面中执行检测"按钮

方法2: 使用 Bookmarklet（最可靠）⭐

为什么这个方法最可靠？直接在 Reddit 页面中执行代码，不受同源策略限制，可以访问所有 Cookie。

步骤：

  1. 在 iframe 中加载 Reddit（或在新窗口中打开 Reddit）
  2. 点击下方按钮复制 Bookmarklet 代码
  3. 在 Reddit 页面的地址栏中，删除当前 URL，粘贴代码，按回车
  4. 会弹出对话框显示登录状态

步骤：

  1. 在 iframe 中打开 Reddit 并登录
  2. 在 Reddit 页面的地址栏输入以下代码（或创建书签）：
javascript:(function(){fetch('https://oauth.reddit.com/api/v1/me',{credentials:'include'}).then(r=>r.json()).then(d=>{const h=!!(d.name||d.id||d.username);alert('登录状态: '+(h?'已登录 - '+d.name:'未登录')+'\n\n完整数据:\n'+JSON.stringify(d,null,2))})})();

或者点击下方按钮复制代码

方法3: 在 Reddit 控制台中执行（最简单）⭐

步骤：

  1. 在 iframe 中加载 Reddit（或在新窗口中打开 Reddit）
  2. 在 Reddit 页面中按 F12 打开开发者工具
  3. 切换到"控制台"（Console）标签
  4. 复制下方代码，粘贴到控制台，按回车
  5. 查看输出结果

检测代码：

fetch('https://oauth.reddit.com/api/v1/me', {credentials: 'include'}) .then(r => r.json()) .then(data => { const loggedIn = !!(data.name || data.id || data.username); console.log('登录状态:', loggedIn ? '✅ 已登录 - ' + data.name : '❌ 未登录'); console.log('完整数据:', data); alert('登录状态: ' + (loggedIn ? '✅ 已登录 - ' + data.name : '❌ 未登录')); }) .catch(e => console.error('检测失败:', e));
