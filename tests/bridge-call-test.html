🔍 Bridge API 实际调用测试

这个页面会直接尝试调用这些 API，看是否能成功执行，而不仅仅是检测"是否存在"。
什么是"边界测试"？
边界测试就是测试"这些 API 在什么情况下还能用"：
1. 主页面：你在 QQ 中直接打开这个页面，能调用这些 API 吗？
2. iframe 子页面：如果这个页面被嵌入到另一个网页的 iframe 里，还能调用这些 API 吗？

为什么重要？
如果 iframe 也能调用 → 说明第三方内容（广告、XSS 攻击）也能调用这些 API（安全风险）
如果 iframe 不能调用 → 说明有隔离保护（相对安全）
